# AGENTS.md

## 项目说明

本项目是《日留学部模拟器》的本地 Web Demo。

它是一个以日本学部生活为题材的养成 SLG 原型。
重点不是做 AI 聊天，而是用本地规则管理游戏流程、数值、事件和 UI，AI 只负责文本演出。

---

## 基本原则

1. 不要把本项目做成聊天窗口。
2. 不要把 UI 做成后台管理页面、表格工具或普通 CRUD。
3. 不要让 AI 决定游戏事实。
4. 不要让 AI 直接修改 GameState。
5. 不要让 AI 输出 HTML。
6. 本地代码负责规则、数值、状态、事件、卡片、关系和结局。
7. AI 只负责根据本地结果生成文本、氛围、事件描写和月度回顾。

---

## 技术栈

当前 Demo 使用：

* C# / .NET
* ASP.NET Core
* HTML
* CSS
* JavaScript

除非明确要求，不要引入：

* React
* Vue
* Tailwind
* Bootstrap
* 数据库
* 大型前端框架

---

## UI 方向

UI 应该有游戏感，而不是表单感。

优先考虑：

* 清晰的信息层级
* 可读性
* 卡片式选择
* 状态变化反馈
* 短期目标
* 风险和压力提示
* 玩家选择后的预测反馈

不要只追求“现代化”“干净”，要让界面看起来像一个可以玩的养成游戏。

---

## 开发方式

每次修改前先阅读现有代码和文档。

修改时：

1. 尽量做小范围改动。
2. 保持项目可以运行。
3. 不要大规模重写无关模块。
4. 不要擅自改变已经存在的游戏机制。
5. 如果需要改变机制，先在回复中说明理由。
6. 完成后说明：

   * 修改了哪些文件
   * 改了什么
   * 是否影响现有接口
   * 如何测试
